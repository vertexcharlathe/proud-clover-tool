# proud-clover-tool



日常脚本的集中地

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/proud-clover-tool.git
cd proud-clover-tool
npm install
```
